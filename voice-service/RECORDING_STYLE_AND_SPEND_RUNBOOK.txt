Recording analysis recovery (v31)
- AAC and other accepted formats are decoded locally to mono 16 kHz FLAC using
  the already-installed PyAV. Actual decoded sample duration enforces 10 minutes;
  malformed media is rejected before metadata writes or provider requests.
- Decoding runs off the API event loop. No original or normalized audio is
  retained after analysis. The live audio path is unchanged.
- Analysis defaults to gemini-3.1-flash-lite, verified with the user's AAC.
  SPEECH_REFERENCE_MODEL can override it; SPEECH_REFERENCE_FALLBACK_MODEL
  defaults to gemini-3.8-flash. At most TWO generation requests total for a
  normal upload. Only temporary 5xx/timeout errors allow the second model;
  quota, permission and invalid-input errors are never retried automatically.
- Gemini 3 analysis requests omit deprecated sampling parameters and use a
  low thinking level (minimal on Flash Lite). Live-call settings are unaffected.

  (the previous 2.5 fallback returned 404). A separately approved single request
  to 3.1 Flash Lite succeeded with eight style rules. Its existing reference
  is READY and enabled. Saved prompts/greeting and other metadata were compared
  before/after and stayed unchanged. Three total requests, no further attempts.
- Error states remain truthful. A busy provider, timeout, missing access or
  quota limit cannot be guaranteed away. FAILED entries display actionable

Operator workflow
1. Open the existing assistant, then Knowledge > Recording.
2. Choose a clear human service conversation, confirm permission to send its
   audio to the configured Gemini provider, then Upload & analyze recording.
3. Uploaded Files lists recordings alongside documents, including processing
   and failed entries. Open Review speaking style for summary and examples.
   Enable style to use it on NEW demo and phone calls. Disable/Delete stops
   its use on future calls. Existing document/URL upload remains available.
4. Human call forwarding opens a compact destination list. Add person adds
   destinations beyond the four legacy slots and opens the editor.
   Enter the name, team and E.164 phone, enable if wanted, then Save.
   Team requests use priority; a named person can be selected by configured ID.
5. Overview > Spend by call type separates Demo, Inbound and Outbound usage.
   The existing date range and USD/INR controls apply to these totals.

Recording behavior
- This supplies style examples to the saved prompt; it is not fine-tuning or
  voice cloning. The selected voice/engine and business/tool rules still apply.
- Common conversational Tamil/Tanglish wording is preferred when appropriate;
  an explicit caller request for pure Tamil or another language takes priority.
- Formats: WAV, MP3, M4A, AAC, OGG, FLAC. Maximum 8 MB / 10 minutes per upload.
  Up to 20 saved profiles, six enabled references, bounded prompt context.
- Duration is validated locally with mutagen before provider access. Recording
  analysis uses the existing Google/BYOK credential and gemini-3.8-flash by
  default; SPEECH_REFERENCE_MODEL may override the analysis model. This does
  not change the live-call model. Analysis may incur Gemini API charges.
- The original upload is held temporarily in memory for one analysis; the
  stored profile contains style data rather than a business-knowledge document.
  Phone/email patterns are redacted. Review the profile before enabling it.
- Analysis has a 140-second overall deadline and at most two requests, with
  a two-second retry only for temporary 500/502/503/504 errors. SDK retries
  are disabled. Quota/permission/format errors are not retried. Errors retain
  safe actionable status codes without private provider diagnostics.
  Expired processing entries show
  a recoverable error. A deleted reference cannot be restored by late analysis.
- New references are disabled until the operator approves them. No recording
  is automatically sent to a provider just by opening the page.
- Occasional acknowledgements and lightly smiling delivery follow context;
  never use constant fillers, stage directions or laughter around distress,
  complaints, confusion or booking/contact details. These are instructions,
  not proof of a particular emotional interpretation or exact voice matching.

  creates no contact, booking, email, SMS or transfer. Business overview call
  and booking KPIs exclude these demo ledger entries.

  text input $0.75; text output $4.50; audio input $3.00; audio output $12.00.
