SAFETY
This is a single-local-API-process Phase 1 facility, not a multi-replica rollout.
The server reserves each test room once and checks existing LiveKit rooms.
Ambiguous dispatch timeouts do not automatically retry that room.
Worker selection trusts dispatch metadata only, never room or participant
metadata. Exact room, assistant, demo marker and direction must match local
configuration. SIP participants are rejected. No silent legacy fallback.
External actions are sandboxed. Existing update_call_details and CallState
rules run locally; availability is a simulated two-second lookup; real
booking/email/calendar/customer-memory writes and human transfers never run.
Booking returns the existing read-only result, not a fake successful booking.
Custom HTTP/MCP business integrations are not invoked in this experiment.
No legacy post-call business callbacks execute. Phone calls stay on the
legacy path and retain their current business-action settings.

- End the browser session; check clean shutdown, final usage and recording.

EVIDENCE AND TIMING
Local journal: voice-service/output/verify/gpt-live/<room>-<timestamp>.jsonl
Local two-channel WAV: existing RECORDINGS_DIR, path logged as recording_finalized.
Caller track is recorded on the existing caller channel; agent channel contains
generated PCM before room playback. It is NOT a handset recording.
No customer Call/Transcript/Appointment rows are created for this browser test;
therefore its recording is not added to the normal customer Calls table.

Journal correlates room/call ID, finalized caller turn ID, delegation ID,
caller transcripts, state snapshots, tool arguments/results, backend start/
first text, non-silent generated segments, SDK speech events, playback start/
finish/position/interruption, usage and shutdown. Events before transcript
finalization can precede a finalized turn ID; use timestamps plus the recording
to align them, rather than subtracting unrelated first events.
Silence does not qualify as generated voice. Non-silent audio is only a
candidate: manually identify the FIRST RELEVANT ANSWER, excluding greeting,
fillers and unrelated speech. Align caller speech end in the recording to
that answer; distinguish generated PCM from room playback. For interruptions,
compare caller onset with actual stopped room playback. Playback-finished
callback time alone is not the exact last audible frame. Handset timing is
NOT measured in a browser test. Meaningful timing fields stay null until
review; no one-second guarantee or automatic quality PASS is inferred.
