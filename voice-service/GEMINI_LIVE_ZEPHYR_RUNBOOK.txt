WHAT WAS VERIFIED ABOUT ZENX
Playwright CLI inspection of https://zenxai.io/ and its public browser client
found Gemini Realtime, gemini-3.1-flash-live-preview and Zephyr in the web-call
request configuration, with LiveKit browser transport. This proves the public
client selection; it does not reveal server overrides, proprietary prompts,
training, or the exact backend used for the supplied historical recording.
Public client: https://zenxai.io/assets/index-CYMpBjsE.js
Local evidence: output/verify/genx-20261110/zenx-public-client.js
Zephyr is a Google built-in synthetic voice; no speaker recording was cloned.
No open-source voice model repository was established as ZenX's provider.
JillJill uses the current Gemini 3.8 Live rather than pinning the legacy preview.
The direct official lifecycle document captured in the earlier audit lists
November 17, 2026 for the 3.1 preview; indexed copies may be stale.

FLOW
Phone -> existing Vobiz SIP -> existing LiveKit room -> Gemini Live native audio
                                                   <-> existing business tools
Browser mic -> existing demo room -> same saved Gemini model/voice
                                   <-> existing sandbox tools only
Native speech uses no external STT/TTS stages or Qwen delegation round-trip.
Tool results are complete, not truncated to the legacy 400-byte response cap.
Gemini usage records its provider/model/tokens without invented OpenAI or Sarvam
costs. Exact Gemini multimodal cost remains unavailable until a rate is configured.

EXISTING FEATURES
Reuses the current assistant's directional business prompts, call state,
knowledge, AppointmentTools, CallTasks, enabled integrations and transfer targets.
Campaign dispatch, phone routing, customer database and booking implementations
remain in place. Browser booking/messages/transfers are simulated and labelled.
Phone actions still depend on the existing real-action setting and integrations.
Existing GPT-Live and cascaded paths remain available for rollback.
The damaged greeting was restored. Existing inbound/outbound prompt bytes were
preserved; form saves now preserve line endings when text is unchanged.
The native voice instructions request everyday Tamil/Tanglish, neutral address,
gentle emotional delivery and one-time email approval. They cannot guarantee
an accent, exact imitation, factual perfection or a maximum response time.
