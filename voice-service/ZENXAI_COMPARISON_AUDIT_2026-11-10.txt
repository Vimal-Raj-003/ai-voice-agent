9. செய்ய வேண்டிய வரிசை மற்றும் acceptance criteria

A. Reproducible transport fixes: audio-rate error, startup backlog, loop stalls.
B. Remove semantic data loss: preserve complete verified results within token limits;
   eliminate full-answer buffering when safe partial information is available.
C. Make saved UI configuration truthful; repair greeting and domain grounding.
D. Existing browser demo-வில் repaired GPT-Live மற்றும் Gemini Live/Zephyr comparison.
   Production phone configuration preserve; fresh model alias/access test first.
E. Same synthetic appointment cases with existing real tool interfaces sandboxed.
F. Voice மற்றும் tools இரண்டும் pass ஆனபிறகு ஒரு controlled user phone test;
   அப்போதுதான் selected assistant-க்கு rollout, easy rollback. Customer calls/messages
   automatic-ஆக தொடங்க வேண்டாம்.

Proposed targets, achieved results அல்ல:
- Simple no-tool questions: caller last word -> first relevant audible answer
  p95 <=1,000 ms target; browser மற்றும் handset தனித்தனியாக அளவிடுதல்.
- Tool-backed answers: completion time separately report; checking filler-ஐ actual
  answer என்று கணக்கிடக்கூடாது. External calendar completion-க்கு 1-second universal
  guarantee தர முடியாது; measured tool time budget தனியாக அமைய வேண்டும்.
- 20 synthetic scenarios அனைத்திலும் correct name rejection, one email confirmation,
  preserved date/time/service, exactly-once booking, no invented success, no re-intake loop.
- Appointment failure/pending/delivery outcomes exact; interruption committed booking-ஐ
  undo செய்ததாகக் கூறாமலும் duplicate submit இல்லாமலும் இருக்க வேண்டும்.
- 3 Tamil listeners மூலம் blinded ordinary Tamil/Tanglish samples; native pronunciation,
  warmth, intelligibility, appropriate emotion மதிப்பீடு; average >=4/5 target.
- Same questions, same network/device conditions, repetitions; p50/p95 and failure counts.
  Browser broadband result-ஐ 8 kHz telephone result-ஆகக் காட்டக்கூடாது.

'100x better' என்பது இப்போது அளந்த metric அல்ல. Better என்பதைக் first useful answer,
native Tamil listening score, correct booking, no repeat questions, reliable interruption
என்ற observable outcomes-ஆக வரையறுப்பதே சரியான engineering இலக்கு.
Source: https://developers.openai.com/cookbook/examples/audio/voice_agent_evaluation
